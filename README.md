# Dream Life CFW

موقع Static جاهز لـ GitHub Pages.

## التشغيل
1. ارفع `index.html` و`style.css` و`script.js` إلى مستودع GitHub.
2. من Settings → Pages اختر Deploy from a branch ثم `main` و`/ (root)`.
3. عدّل روابط Discord وFiveM والمتجر داخل `index.html` و`script.js`.

لا يحتاج الموقع إلى Node.js أو قاعدة بيانات.
